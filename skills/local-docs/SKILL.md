# Local Documents (`docs/`)

Work with local markdown files in the `docs/` directory.

- **Find**: Use Glob to match filenames in `docs/`
- **Read**: Use the Read tool on any `.md` file
- **Search**: Use Grep to search content across `docs/`
- **Create**: Use Write to create a new `.md` file in `docs/`
- **Update**: Use StrReplace to edit an existing `.md` file
